Every non-2xx response contains this envelope. The fields are under `error`, not at the top level.

```json
{
  "error": {
    "type": "permission",
    "code": "user_action_required",
    "message": "…",
    "param": "inbound_amount",
    "detail": { "url": "https://final.com/…" },
    "request_id": "req_…"
  }
}
```

## Every connection route

Every route that accepts `Final-Connection` can return these errors before the route runs.

| Status | Code | Description |
| --- | --- | --- |
| 404 | `connection_not_found` | The id is unknown, the key or the mode is wrong, the secret is wrong, or the connection is not active yet. Final uses one code for all of these on purpose. |
| 403 | `connection_revoked` | The user revoked the connection, the connection became dormant, or your integrator account is closed, locked or in review. Connect again. |
| 403 | `verification_pending` | The user's account is in review. Every call returns this error until the review ends. |
| 403 | `region_not_supported`, `region_unverified` | The error type is `compliance`. The cause is the region of the request. |
| 400 | `connection_header_unexpected` | You sent `Final-Connection` to a route that does not accept it, such as `POST /intents` or activation. |
| 403 | `origin_not_allowed` | The browser sent an `Origin` that is not registered for this publishable key. |
| 429 | `rate_limited` | Wait for the time in `Retry-After` before you send the next request. For more information, see [Rate limits](/reference/rate-limits). |

If a Balance or a card is not in your grant, Final returns `404 not_found`. Final returns the same error for a Balance or a card that does not exist.

## Proposals and activation

| Status | Code | Description |
| --- | --- | --- |
| 400 | `code_challenge_required`, `code_challenge_invalid` | A request with a publishable key must contain an `S256` challenge. |
| 400 | `intent_payload_invalid` | The request has no assets or more than 8 assets. Or a Balance cannot contain an asset, or the asset is not available in this mode. |
| 400 | `redirect_uri_required` | A live proposal with a challenge must contain a redirect URI. |
| 400 | `redirect_uri_invalid` | The redirect URI is not an absolute URL, contains a wildcard or userinfo, or uses `http://`. |
| 400 | `redirect_uri_unregistered` | The redirect URI is not an exact match for one of your registered redirect URIs. |
| 400 | `reference_not_allowed`, `reference_invalid` | Only a secret key can send `reference`. The value can have up to 256 printable characters. |
| 400 | `intent_kind_unsupported` | The kind is not `account.connect`. |
| 403 | `integrator_profile_required` | Save a profile first. |
| 403 | `integrator_unverified` | Final must verify you before you can use live mode. Until then, you can use test mode. |
| 404 | `connection_not_found` | On activation, the code, the verifier or the key is wrong, or the connection is already active. |
| 409 | `activation_code_expired` | The code is older than 10 minutes. Propose again. |
| 503 | `asset_chain_unavailable` | The chain of an asset is temporarily unavailable. |

## Balances

| Status | Code | Description |
| --- | --- | --- |
| 400 | `connection_root_not_allowed` | You sent `POST /balances` without `parent_balance_id`. Final creates a root Balance only when the user approves. |
| 400 | `parent_invalid`, `depth_exceeded`, `limit_invalid` | The sub-balance request is not valid. |
| 503 | `asset_chain_unavailable` | The chain of the asset is temporarily unavailable. |

## Deposits

| Status | Code | Description |
| --- | --- | --- |
| 400 | `invalid_amount` | Send exactly one amount, as a positive integer string. |
| 400 | `no_inflow_route` | No swap into this asset is available in this mode. |
| 400 | `test_behavior_not_allowed`, `test_behavior_invalid` | You sent `Final-Test-Behavior` with a live credential, or with an unknown value. |
| 400 | `ends_at_out_of_range` | A routing window must end in the future and within 24 hours. |
| 404 | `balance_not_found` | The Balance is not a root Balance in your grant, or the grant does not contain `direct_deposit`. |
| 404 | `override_not_found` | You did not open this routing window, or the window is already closed. |
| 409 | `override_in_flight` | The account can have only one routing window, and that window is already open. |
| 503 | `direct_deposit_unavailable` | Direct deposit is paused. Send the request again soon. |
| 400 | `base_required`, `quote_required`, `asset_unknown`, `pair_unpriceable` | `GET /exchange_rate` returns these errors. |
| 503 | `rates_unavailable` | Final has no configured rate source. |

## Cards

| Status | Code | Description |
| --- | --- | --- |
| 400 | `balance_id_required` | The request does not contain `balance_id`. |
| 400 | `status_invalid` | The value of `?status=` is not `active`, `provisioning`, `frozen`, `closed` or `all`. |
| 400 | `invalid_amount`, `merchant_name_required` | The body of the test authorization is not valid. |
| 409 | `balance_closed` | The Balance is closed. |
| 409 | `card_provisioning`, `card_closed` | The card is not active yet, or the card is closed. |
| 503 | `cardauth_unavailable` | Card authorization is temporarily unavailable. |

## Everywhere

| Status | Code | Description |
| --- | --- | --- |
| 400 | `body_invalid` | Final cannot parse the JSON body. |
| 400 | `id_invalid` | An id in the path is not in the correct format. |
| 403 | `terms_unaccepted` | The user must accept new Final terms. A connection gets this error as `user_action_required`. |
| 409 | `idempotency_key_reused`, `idempotency_in_flight` | For more information, see [Idempotency](/reference/idempotency). |
